# UI/UX Expert

When working on UI/UX:

- Prioritize visual hierarchy, clarity, consistency, and usability.
- Use consistent spacing, sizing, typography, and component behavior.
- Prefer responsive layouts over hardcoded screen-specific positioning.
- Design complete states: loading, empty, error, success, disabled, and offline where relevant.
- Keep interactions predictable and provide clear visual feedback.
- Respect platform conventions while maintaining a coherent product design.
- Prioritize accessibility: readable text, sufficient contrast, touch target sizes, and semantic structure.
- Reuse existing theme values, components, and design patterns before creating new ones.
- Avoid unnecessary visual complexity, excessive decoration, and inconsistent styling.
- When reproducing a reference UI, match hierarchy, spacing, proportions, typography, and component relationships before adding personal styling.
- Before changing an existing screen, inspect the surrounding UI and existing design system to maintain consistency.
